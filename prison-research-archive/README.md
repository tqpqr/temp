# Prison research archive — additive catalogue

This directory is an **add-only research index** for the pre-existing files in `tqpqr/temp`.

## Preservation policy

- Do not delete, move, rename, replace, or modify existing original files.
- New categorised copies must retain a verifiable link to their original paths.
- Keep separate original and transformed research datasets; describe every transformation.
- Preserve uncertain classifications as uncertain.
- Existing identical binary files are *recorded*, never removed.

- Baseline entries: 1,124 files and 59 directory tree entries.
- Total blob payload as reported by Git: approximately 1,292 MiB.

- `00_catalog/source_inventory.csv` records one row for **each** baseline blob: original path, extension, bytes, Git blob SHA-1, original link, and blank enrichment fields.
- SHA-1 values are Git object identities, **not** SHA-256 checksums. Future SHA-256 checks require byte-level access.
- Content summaries, underlying data tables, statistical variable definitions, time coverage and provenance have **not** yet been independently audited.
- The original_url column uses the pinned tree identifier as its GitHub path reference; if browsing by that identifier is unsupported by GitHub UI, resolve from the recorded `original_path` on the baseline branch/history.
