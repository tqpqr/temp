# What is stored and how strong is the evidence?

**International:** 111 `space-archive/` files contain SPACE I prisoner/penal administration annual reports, SPACE II probation reports, key findings, official country institution/capacity references and economic PPP conversions. The 34 rows in `space-archive/manifest.csv` and 20 in `manifest-space-ii.csv` together refer to **52 unique tracked files**, because two files occur in both manifests (SPACE II 2022, SPACE I 2025). Their source URLs and supplied SHA-256 strings are retained in the copy manifest; SHA-256 has not been recomputed. Another 14 `extra/` files are supplementary national sources, potentially same-content versions. SPACE prison capacities are heterogeneous; Italian *capienza regolamentare* is not necessarily operational capacity. GDP PPP differs from government consumption PPP.

**Britain:** 271 UK originals were already fully mirrored and SHA-verified: **189** monthly population bulletins, **53** workforce workbooks, **27** per-prison cost documents FY2014/15–2024/25, **one** population methodology annex and **one** NAO audit. Existing `00_catalog/gb_*.md` documents and `02_uk/*.csv` extracts include workforce/occupancy/cost analyses, official establishment-function reconciliations and sensitivity panels. Yet 8 monthly bulletin filenames remain ambiguously dated from the initial screen; many cost and staff sheets still need full audit. Do not silently combine FTE, occupancy stocks, fiscal-year costs, restated tables, private/public operators or adult/Youth Custody Estate.

**Russia:** `sud/`: **507** year-organized court reporting documents; raw report-form headings and methodological continuity require per-file inspection. `fs-22/`: **49** budget/justice documents and 7z files. `fsin/`: **2** workbook/description sources, spreadsheet cells not all decoded. `svod/`: **28** government reports including opaque PDFs. `data_crimes_stat/`: **3** criminal statistical files. Judicial conviction/sentencing flows are different from prison inmate stock; budget execution differs from appropriation/staff ceilings.

**United States:** `jeet/` contains **20** BJS Justice Expenditure and Employment Tool workbooks in 2016–21 folders, seven XML worksheets each; official statistical function *Corrections*, 50 states and DC, metrics *Expenditures Per Capita*, *Employees Per 10k Residents* and *Average Pay*. This government function is **not prisons alone**. Some different 2018 binaries have equivalent worksheet XML; 2016 and 2017 repeat certain aggregate values, demanding follow-up. The official BJS agency documentation is identified, not a recovered personal download trail. `us/` contains **9** more corrections, government-finance and fixed-width/codebook extracts; local-government corrections spending cannot be treated as per-prison budgets.

**Context/unresolved:** **39** Russian socioeconomic control XLSX files, **one** research table extraction Python script, **nine** unidentified `rn1` PDFs, **four** otherwise unclassified government/legal root documents. The 57 `alt/`, `alt2/`, `alt3/` satellite/geological items remain outside this research archive, untouched at origin.

### Provenance interpretation

For every file the copy manifest provides a **source repository path + original Git object SHA + new identical SHA**. This is proven repository provenance. External origin is recorded only where prior manifests or verified agency identification provide evidence. Empty external URL does not authorize inventing a link. Description tags sometimes reflect filenames/families rather than inspected worksheet or PDF content. All source and transformed versions remain separate.
