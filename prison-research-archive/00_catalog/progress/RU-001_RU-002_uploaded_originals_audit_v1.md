## RU-001: F2-2024.xls

Фактическая форма № 1-АП — «Отчет о работе судов общей юрисдикции по рассмотрению дел об административных правонарушениях». Титул: D4 название, G6=12 месяцев, I6=2024, K9 номер формы. Полугодовая периодичность формы не отменяет явно указанного двенадцатимесячного периода данного отчёта. Организация — Судебный департамент при Верховном Суде РФ. Семь листов, разделы 1–11.

Раздел 1 содержит результаты первой инстанции по статьям КоАП: движение дел, прекращения, категории лиц, основные и дополнительные наказания, суммы штрафов. Другие разделы — обеспечительные меры, обжалование, дисквалификация и другие специальные показатели. Раздел 11 содержит разбивку кассационных результатов по территориям; её нельзя распространить на все показатели книги.

Опорные значения листа «Раздел 1»: F10=5953669 рассмотренных дел (по числу лиц); M10=4910415 лиц, подвергнутых наказанию; T10=648690 административных арестов в классификации основных наказаний; S10=3553125 административных штрафов как основных наказаний; AD10=65122385957 рублей штрафов, наложенных по вынесенным в отчётном периоде постановлениям первой инстанции.

Две проверенные идентичности: M10 = сумма N10:Q10 = сумма R10:Z10 = 4910415. Дополнительные наказания AA:AC нельзя прибавлять к этому итогу как новых лиц. Суммы назначенных и взысканных штрафов имеют разные временные основания. Административный арест не является уголовным лишением свободы; эти данные не измеряют контингент учреждений ФСИН.

## RU-002: K3-2024.xls

Фактическая форма № 10-а — отчёт о числе осуждённых по всем составам преступлений УК РФ и иных лиц, в отношении которых вынесены судебные акты по уголовным делам. Титул D4, G6=12, I6=2024, K8 номер формы. 21 лист: титул, сводный раздел 1, подробные разделы 2–18, 20, 21. Листа «Раздел 19 (Гл. 33)» в книге нет.

«Раздел 1» D8=512845 осуждённых по основной статье, G8=990 оправданных по основной статье; J8=651 прекращение по реабилитирующим основаниям, M8=118775 по иным основаниям, P8=7516 лиц с принудительными медицинскими мерами по основной статье. Это судебные исходы за период, не число содержащихся в тюрьмах и не распределение видов назначенного уголовного наказания.

Колонки дополнительных квалификаций различают число лиц и число составов. Сноска A31 допускает несколько составов на человека: суммы лиц по группам нельзя автоматически считать непересекающимися.

### Обнаруженное ограничение полноты

В A8 написано «сумма строк 2, 8, 12, 18, 23, 24», но фактические номера сводных строк заканчиваются на 23. Строки 24 нет. В названиях листов также отсутствует раздел 19 / глава 33; поиск текстового заголовка главы 33 по всем ячейкам результата не дал.

Для основных осуждений видимые разделы дают 503639 против общего итога 512845: разница 9206. Это вычисленный остаток, а не опубликованное значение отсутствующей строки. Не присваивать ему автоматически категорию военных преступлений. Причина отсутствия строки и статус полноты публикации не установлены. Для дополнительных квалификаций по числу лиц остатки могут быть отрицательными из-за пересечения групп — это не самостоятельное доказательство арифметической ошибки.

## Что исправлять в каталоге следующим шагом

1. RU-001 и RU-002: техническое препятствие к чтению устранено; имеются названия, периоды, листы и адреса исходных ячеек. Существующие BLOCKED-записи не переписаны.
2. Для F2 зафиксировать форму 1-АП и административную предметную область; для K3 форму 10-а и уголовные судебные исходы. Имена файлов не являются номерами форм.
3. Добавить отдельную оговорку о неполной детализации K3 и невозможности восстановить отсутствующую строку как факт простым вычитанием.
4. Перед объявлением полного арифметического аудита выполнить контрольные соотношения остальных разделов. Текущая проверка этого не заявляет.

Приложения: два полных перечня листов с размерами и числом заполненных/error-ячеек, JSON идентичности и проверок, скрипт audit.py. Скрипт ожидает неизменённые оригиналы в соседней папке upload. Оригиналы в пакет повторно не включены.
