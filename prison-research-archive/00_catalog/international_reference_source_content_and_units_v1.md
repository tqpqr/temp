# International source content audit: Germany / PPP / currencies — 2026-10-14

## Germany — authoritative national statistical source tables actually opened

**Both XLSX workbooks were read directly as ZIP and decompressed into their own original Excel rows, not identified only by filename.**

1. `extra/24321-0001_de.xlsx`, original Git SHA-1 `74df8bd6268615901f75224fc6f296ca3ac23869`, one worksheet `24321-0001`, **108 nonempty original XML rows**, up to 57 columns. Official Destatis / GENESIS table code 24321-0001, external official source page: https://genesis.destatis.de/datenbank/online/table/24321-0001 . Prisoners and preventive detainees grouped by nationality, sex, age band, and detention type (`Freiheitsstrafe`, `Jugendstrafe`, `Sicherungsverwahrung`), observed **31 March 2017–31 March 2025**, nine cross-sections. Original workbook contains internal provenance timestamp **10 October 2026**. Important 2023 definition note near source rows 107–109: from 31.03.2023, `männlich` includes `divers` and `ohne Angabe`. These are **detention-stock breakdowns, not annual conviction flows**.
2. `extra/24321-0003_de.xlsx`, Git SHA-1 `f8a896c430fac0f06ad5f133243835a947de33af`, worksheet `24321-0003`, **26 original XML rows**, 7 columns. Official GENESIS `Strafvollzugsstatistik` table title is `Justizvollzugsanstalten, Belegungskapazität, Belegung: Bundesländer, Stichtag`. **This local file contains only 30 November 2015**, **not** all years in the live GENESIS series. Row 3 contains number of prison institutions (`Justizvollzugsanstalten`), rated/occupancy capacity (`Belegungskapazität`) and actual detained occupancy (`Belegung`) by federal state. Rows 24–25 explicitly define `Belegung` as **excluding temporarily absent people, especially `Hafturlauber`**. Export footer dated 10 October 2026. Official agency statistical listing verifies table code: https://genesis.destatis.de/datenbank/online/statistic/24321/details .
3. Germany's `Belegungskapazität` is not assumed interchangeable with English `In Use CNA`, `Operational Capacity` or SPACE nominal places. The German `Belegung` excludes temporary authorized absence, while old GB bulletins explicitly allow their `Population` to include persons on authorized absence. This is a **real source-definition contrast**, not an inferred statistical correction.

## World Bank data files — actual local CSV metadata

- `extra/wb/Metadata_Indicator_API_NY.GDP.DEFL.ZS_DS2_en_csv_v2_7255.csv` (Git SHA `ecada730b98ee0d6abcbee893f6c6ea8691b4823`) defines the GDP implicit deflator: current-local-currency GDP divided by constant-local-currency GDP; country-dependent base year.
- `extra/wb/Metadata_Indicator_API_PA.NUS.FCRF_DS2_en_csv_v2_3350.csv` (SHA `9d403bc9f6dd2320701a4677ee2d99a3a11cc197`) defines the **official exchange rate** in LCU per USD (annual/period mean), via IMF International Financial Statistics.
- `extra/wb/Metadata_Indicator_API_PA.NUS.PPP_DS2_en_csv_v2_6254.csv` (SHA `ddaa7e58ed5bf9c7decb5ea9b0ab43a9909bf9`) defines **GDP-level** purchasing-power-parity factor LCU per international dollar. GDP PPP is **not** specifically a government-services PPP.
- The separate `extra/wb/ICP2021_PPP_GovFinalConsumption_9270000.csv` (SHA `406ca43b42442341f4d9b172de3ebb9fb97e2aee`) contains `9270000: General government final consumption expenditure`, columns 2017–2023, national ISO3 codes and LCU/USD government-consumption PPP. Many source cells in 2022–2023 are blank, while values for 2017–2021 are present for several countries. Do not fill blank future years by copying 2021 levels without a separate documented imputation method.
- WDI `extra/wb/API_PA.NUS.PPP_DS2_en_csv_v2_6254.csv` literally includes header `Last Updated Date, 2026-10-08`, year headers 1960–2025. **This is a source snapshot date**, not identical to the historical observation year. The same applies to other World Bank WDI slices.

## US Census related distinction

- `us/raw data/jail/local_govt_correction_expenditure_2012_2017_2022.csv` (Git SHA `ac58f74a697fe4e711332fbafbe6df7f34df36c8`) was read. It contains local-government `Correction` financing in Census years 2012, 2017, 2022. `E04` direct expenditure, `F04` current operations, `G04` capital outlay; amounts recorded in **thousands of current US dollars**. It explicitly states derivation from US Census via Urban Institute State and Local Finance Data, accessed 30 Aug 2026: https://state-local-finance-data.taxpolicycenter.org .
- The associated workbook `us/raw data/jail/local_govt_correction_expenditure_2012_2017_2022.xlsx` (Git SHA `00355281625c5fc76acc21bbe529ef6a7b7b969f`) was opened, original rows and figures agree with the CSV on three items and three years. These are **local governments**. Separate `us/raw data/2011/11state35.txt` contains **state-government** finance records, and cannot be joined or totalled without distinguishing levels and years.

## Provenance limits

Agency-verified *dataset web pages* and collection-specific source metadata are linked; **original per-file download events have not been recovered or re-hashed from third-party servers**. Git original SHA-1 identifies source as stored in this repository. For source-derived figures, distinguish denominator (resident vs prison population), price level (nominal vs deflated), PPP type, year vs reporting date and institutional universe.
